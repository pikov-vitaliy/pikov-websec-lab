# Laboratory Guide Index

Материалы Pikov WebSec Lab разделены по аудитории, чтобы ответы преподавателя не
попадали в задание слушателя.

- [Student Guide](student-guide.md) — порядок выполнения, вопросы и шаблон
  доказательств без ответов.
- [Instructor Guide](instructor-guide.md) — preflight, тайминг на 10/30/60 минут,
  подсказки, ответы, reset и troubleshooting.
- [Assessment Rubric](assessment-rubric.md) — единые критерии оценивания.
- [Vulnerability Analysis](vulnerability-analysis.md) — технический разбор и
  нормативные привязки.
- [Architecture and Security Model](architecture-and-security-model.md) —
  компоненты, границы доверия и ограничения стенда.
