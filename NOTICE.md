This edition adds a distinct project name, safer classroom operating guidance,
separate student and instructor materials, an assessment rubric, an explicit
architecture/security model, standards mappings, and a non-exfiltrating local
SVG canary. Source and runtime changes, when present, remain described by the
Git history.
